# MEAN Prep Lab

A playful, single page study space for **MEAN Stack Developer Interview Questions & Preparation Guide**.

## What is inside

- An interactive request journey through Angular, Express, Node.js and MongoDB
- Flip flashcards with real interview questions, filterable by layer
- A four week prep checklist with a live progress bar
- Clickable cards for live online MEAN, Full Stack Pro, MERN and Python courses in Delhi
- Blog links for deeper reading, a sticky header and a full footer

## Run it

No build step. Open `index.html` in a browser.

## Publish with GitHub Pages

1. Push `index.html` and `README.md` to your repository.
2. Open Settings, then Pages.
3. Choose the main branch and the root folder, then save.
4. Your page goes live at `https://<your-username>.github.io/<repo-name>/`.

## Design notes

Palette: deep purple, bright yellow, neon blue and white. Fonts: Bricolage Grotesque and Figtree from Google Fonts, with system fallbacks. Fully responsive, keyboard friendly and respects reduced motion.

## Customise

Edit the `qs` array in `index.html` to add flashcards and the `plan` array to change the checklist.
